# Drug-Target-Interaction-DTI-Prediction
This project is an integrated Drug-Target Interaction (DTI) Prediction system, which is a vital field in bioinformatics and AI-driven drug discovery.  The code shows that the project was collaboratively developed by a team (Person A, B, C, D, E) to combine several distinct approaches (classical models, deep learning, and text processing) and compare their performance.  Key Components & Features of the Project:Data Loading and Cleaning (data.py & config.py):Handles popular drug discovery datasets such as Davis and KIBA.  Cleans data, removes missing values and duplicates, and validates molecular SMILES strings using RDKit.  Categorizes drug-target pairs into binders and non-binders based on specific biochemical thresholds (e.g., $pKd \ge 7.0$).  Performs Exploratory Data Analysis (EDA), analyzing affinity score distributions and class imbalances.  Feature Engineering (features.py):Converts chemical structures into numerical representations using Morgan Fingerprints (ECFP4) with 2048 bits.  Extracts physicochemical properties (Molecular Descriptors like molecular weight and polarity).  Computes amino acid composition for protein sequences.  Implements TF-IDF Character N-Grams as an alternative text-based approach for drugs and proteins without requiring complex chemistry libraries (Person B's approach).  Handles class imbalance with SMOTE and applies StandardScaler and SelectKBest for feature selection.  Classical Machine Learning Models (models_classical.py):Trains strong baseline and advanced models including Ridge Regression, Random Forest, and XGBoost (used for both classification and continuous pKd regression).  Uses GridSearchCV for hyperparameter tuning.  Deep Learning Models (models_deep.py):Implements deep LSTM networks to process drug and protein sequences (Person A and Person C approaches with speed and processing enhancements).  Builds a multi-layer perceptron neural network using PyTorch (DTAPredictor) featuring batch normalization and dropout.  Evaluation & Interpretation (evaluate.py):Calculates comprehensive metrics including MSE, RMSE, R², Pearson Correlation, Concordance Index (CI) for ranking evaluation, along with classification metrics like Accuracy, F1-Score, and ROC-AUC.  Generates visual comparison plots (Parity Plots and Model Comparison Charts).  Interprets AI decisions using SHAP analysis, feature importance plots, and error analysis to identify where models struggle.  Recommendation System & User Interface (recommend.py, ui.py, & main.py):Recommendation System: Allows input of a target protein so the model scans a drug library and ranks the top recommended candidate drugs based on predicted affinity.  Interactive UI (Gradio UI): Provides a web interface for easy system testing and visualization.
